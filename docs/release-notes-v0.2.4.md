# TFC 锻造助手 v0.2.4

继续缩短批量换件后的停顿。

下载 `tfc-forge-helper-0.2.4-windows-x64.zip`，先关闭旧版，再解压运行新版 `TFC-Forge-Helper.exe`。无需安装 Python，原有设置保留。

- 同一批次复用识别器及已验证的砧位置，不再每件重建模板和全屏寻找砧。
- 直接使用刚确认完成补料的画面，去掉下一件开始前的重复截图。每件仍独立识别和求解自己的 current、target、规则及历史，不沿用上一件方案。
- 周期性游戏进程扫描移到执行之外；批次期间固定当前游戏进程，保留前台、窗口位置、遮挡、F9 和资源变化检查。
- 缓存定位仍会验证，GUI 移动后重新寻找；不使用其他进程的画面继续操作。

相同四件一动作配方的模拟任务中，补料完成到下一件首击的空档中位数从 **144 毫秒降到 9 毫秒**，总耗时从 **1.666 秒降到 1.123 秒**。均不含启动倒计时；实机表现仍取决于帧率、服务器响应及配方，详见 `docs/performance.md`。

128 项本地测试通过，另有 EXE 无窗口独立运行检查。没有向真实游戏发送测试输入；尚未完成真实 TFC 自动锻造端到端验收。
