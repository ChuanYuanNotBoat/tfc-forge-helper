# 自动锻造速度

## v0.2.4 换件间隙

2026-10-25，同机比较 v0.2.3 和 v0.2.4。任务为四件一动作配方，包含补料、余料归位和收回成品；各运行三次，均不启用性能分析器。其余模拟方法与下节相同，保留 40 毫秒鼠标按住时间，不含启动倒计时。

| 指标（中位数） | v0.2.3 | v0.2.4 |
| --- | ---: | ---: |
| 补料最后一击释放后，到下一件首击的空档 | 144.28 毫秒 | 8.60 毫秒 |
| 同一段间隔，按两次按下时刻计算，含前一次按住时间 | 187.96 毫秒 | 52.07 毫秒 |
| 四件批量总耗时 | 1.666 秒 | 1.123 秒 |

区别主要是批次内共享识别器，复用已验证位置及刚确认的进料画面，免去逐件全屏搜索和额外截图。每件的目标、当前位置和规则仍独立读取、求解。位置验证失败时重新搜索；进程或窗口不符会停止输入。

另用本机现有配置做只读测量：一次初始实例/资源刷新约 885.74 毫秒，后续资源刷新中位数约 3.14 毫秒。v0.2.4 将周期性进程发现移出执行中的批次，固定开始时的游戏进程；资源文件签名和原生窗口检查继续运行。此测量没有截取屏幕像素、移动鼠标或发送输入。

## v0.2.3 整体加速

2026-10-25，Windows x64 / Python 3.12.10，同机比较 v0.2.2 与 v0.2.3 默认执行参数。

| 模拟任务 | v0.2.2 中位耗时 | v0.2.3 中位耗时 | 速度提升 |
| --- | ---: | ---: | ---: |
| 单件七步，83 → 108，hit_third_last / draw_second_last / draw_last | 2.047 秒 | 0.830 秒 | 2.46 倍 |
| 三件一动作配方，包含补料、余料归位和收回成品 | 4.171 秒 | 1.221 秒 | 3.41 倍 |

各运行三次，使用测试中的原创诊断贴图、`FakeGame` / `InventoryGame` 模拟接口和真实识别/求解/执行流程。每次模拟点击额外保留 40 毫秒按住时间，和 Windows 输入后端一致；不包含仅启动一次的 3 秒倒计时。不打开或点击真实游戏。

原始耗时（秒）：

- 单件旧版：2.033974、2.046544、2.054112；新版：0.823142、0.830083、0.832793。
- 批量旧版：4.189696、4.140531、4.170732；新版：1.221042、1.221169、1.267243。

新版每件只在开始时读取完整锻造状态、求解一次，结束时确认结果；不在每次动作之间截图、识别和重算。每件补料后均重新求解，独立适配随机目标和规则。锻造动作固定等待为 40 毫秒；批量取放不插入固定空等，已确认的成品画面直接用于收回，不重复截图。只在等待未更新的画面时每轮间隔 20 毫秒，仍不重试点击或序列。

以上是可控模拟条件下的处理速度，不能等同于所有游戏环境的实测速率；真实帧率、截图耗时、服务器 tick 和网络延迟都会影响完成时间。尚未完成真实 TFC 自动锻造端到端验收。
