# TFC 锻造助手 v0.2.5

新增开始自动打铁的全局快捷键 **F7**，在游戏中直接使用，无需切回助手窗口。

| 快捷键 | 功能 |
| --- | --- |
| F7 | 开始自动打铁，保留三秒倒计时 |
| F8 | 识别屏幕 |
| F9 | 停止执行，或取消正在等待识别结束的启动请求 |

按住 F7 不会重复触发，执行中或倒计时中再次按下不会重启。若正在识别，启动请求排队一次。F7 被其他程序占用时可用窗口内的开始按钮；F9 不可用时仍禁止启动。快捷键操作不打开新窗口、不抢占焦点。

下载 `tfc-forge-helper-0.2.5-windows-x64.zip`，关闭旧版后解压运行 `TFC-Forge-Helper.exe`。无需安装 Python，原有设置保留。

135 项本地测试通过，包含 7 项新增快捷键回归；全局热键和输入接口测试使用模拟绑定，没有向真实游戏发送操作。另经无窗口 EXE 独立运行检查，尚未完成真实 TFC 自动锻造端到端验收。
