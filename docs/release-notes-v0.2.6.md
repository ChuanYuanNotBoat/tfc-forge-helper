# TFC 锻造助手 v0.2.6

配置和运行偏好自动保存，重启后恢复：

- 实例目录、TFC JAR、额外资源包、校准路径和自动定位开关。
- 截图显示器、容差、批量开关及加工数量。
- 连续识别、小窗开关和主窗口置顶。

修改后自动保存，关闭时立即补存，无需先打开游戏或成功检测资源。EXE 配置仍位于 `%LOCALAPPDATA%\TFCForgeHelper\settings.json`，升级兼容旧版格式。自动执行临时暂停连续识别不会覆盖用户保存的偏好。

未输入完整的数字保留上次有效值；配置采用原子写入，保存失败只在状态栏提示。当前坯料的数值、历史、方案和执行任务不跨重启恢复，打开助手不会自动开始打铁。F7 开始、F8 识别、F9 停止保持不变。

下载 `tfc-forge-helper-0.2.6-windows-x64.zip`，先关闭旧版，再解压运行 `TFC-Forge-Helper.exe`。无需安装 Python。

150 项本地测试通过，新增 15 项设置持久化回归；另经 EXE 无窗口独立运行检查。测试没有打开桌面窗口或向真实游戏发送操作，尚未完成真实 TFC 自动锻造端到端验收。
