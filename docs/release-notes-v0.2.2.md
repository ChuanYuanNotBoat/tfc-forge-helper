# TFC 锻造助手 v0.2.2

修复连续识别时方案被遮挡帧反复清空的问题。

下载 `tfc-forge-helper-0.2.2-windows-x64.zip`，关闭旧版助手，解压后运行 `TFC-Forge-Helper.exe`。无需安装 Python；打包版原有设置会保留。

## 改进

- 鼠标、提示框或临时遮挡导致识别失败时，保留上一次有效方案和小窗提示，不显示低匹配度错误来覆盖它们。
- 只有可靠识别到当前位置、目标、规则或最近历史发生变化时才更新显示。同一状态不反复重绘，匹配度、窗口位置和缩放波动不再打断查看。
- 后台扫描不反复切换为加载文字；每轮完成后等待约一秒再扫描。
- 暂停连续识别也保留当前显示；F8 / 按钮手动识别失败、修改输入、切换实例或资源仍会清除旧方案。

## 验证与限制

114 项本地测试通过，新增 18 项连续识别界面回归测试。Windows x64 EXE 另经项目外独立运行检查；附件提供 SHA-256 校验值。

保留的显示代表上一次成功识别的状态。自动打铁会独立重新读取并校验屏幕，不使用保留的显示方案发送点击；识别失败仍会停止自动操作。自动执行测试使用模拟接口，尚未在真实 TFC 游戏中完成自动锻造端到端验收。
