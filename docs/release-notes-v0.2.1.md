# TFC 锻造助手 v0.2.1

Windows x64 外部锻造助手，适用于 TerraFirmaCraft / Minecraft 1.21.1，采用 MIT 许可证。

## 下载和启动

下载 `tfc-forge-helper-0.2.1-windows-x64.zip`，完整解压后双击 `TFC-Forge-Helper.exe`，无需安装 Python。`SHA256SUMS.txt` 提供附件校验值。源码包和 wheel 面向开发者，普通用户使用 Windows ZIP 即可。

首件原料放入砧并选好配方后，可按 F8 识别，或点击“开始自动打铁（3 秒）”并切回游戏。F9 随时停止。批量模式默认开启，数量 0 表示处理全部同类原料。每次补料后重新识别并求解该件状态。

## 功能与修复

- 自动定位游戏实例，识别当前位置、目标、规则和最近三步，计算最少剩余操作。
- 按资源包优先级构造识别模板，支持整数 GUI 缩放和多显示器窗口截图。
- 自动锻造逐步校验反馈；支持批量补料、余料归位和收回成品。
- 修复窗口部分移出屏幕时停放点越界导致无法启动批量的问题。
- 打包版设置保存在 `%LOCALAPPDATA%\TFCForgeHelper`，支持更新后保留。

## 验证与限制

发布前通过 96 项逻辑、识别、模拟自动执行、坐标接口和配置路径测试，并执行独立 EXE 冒烟检查。自动执行测试使用模拟输入接口；**尚未在真实 TFC 游戏中完成自动锻造端到端验收**。

需要用户本地的游戏实例及砧贴图，不随包分发游戏 JAR、TFC 贴图或用户材质包。不自动加热、不自动更换锤子。非整数缩放、改动布局的模组以及目标容差范围括号等兼容边界见 README。EXE 未使用代码签名证书。
